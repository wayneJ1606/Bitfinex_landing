# Bitfinex System Flow Motion Graphic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a verified 25-second, 1920×1080 HyperFrames motion graphic that explains the Bitfinex lending system data flow without inventing model results.

**Architecture:** Create an isolated HyperFrames project under `videos/bitfinex-system-flow/`. Use one deterministic standalone composition with a single paused GSAP timeline, six timed narrative phases, code-native vector shapes, and no external media dependency. Validate with HyperFrames lint/check and three proof snapshots; render MP4 only after explicit user approval.

**Tech Stack:** HyperFrames 0.7.78, HTML/CSS, GSAP, Node.js 22+, FFmpeg, HyperFrames `motion-graphics` workflow.

## Global Constraints

- Canvas is exactly 1920×1080, 16:9.
- Target duration is 25 seconds.
- Language is Traditional Chinese.
- No narration; the piece must be understandable without audio.
- Project files live only under `videos/bitfinex-system-flow/`.
- Use the verified state `80 / 168` for each market.
- Do not display invented MAE, RMSE, R², yield, fill-rate, or profit values.
- Model cards remain visibly gated until the 168-row threshold is reached.
- The final message is `資料驅動・可重現・不自動下單`.
- Use a deterministic, seek-safe, paused GSAP timeline with no network calls, runtime clocks, infinite repeats, or unseeded randomness.
- Formal render requires explicit user approval after proof snapshots and final preview.

## File Structure

- Create `videos/bitfinex-system-flow/BRIEF.md`: confirmed intent, output rules, message, and truth constraints.
- Create `videos/bitfinex-system-flow/hyperframes.json`: HyperFrames project metadata generated by `init`.
- Create `videos/bitfinex-system-flow/package.json`: pinned project CLI scripts generated by `init`.
- Create `videos/bitfinex-system-flow/shot-plan.json`: motion-graphics category, beats, layout, palette, and proof times.
- Create `videos/bitfinex-system-flow/compositions/index.html`: complete standalone renderable composition.
- Generate `videos/bitfinex-system-flow/snapshots/`: proof frames and contact sheet.
- Generate after approval `videos/bitfinex-system-flow/renders/bitfinex-system-flow.mp4`.

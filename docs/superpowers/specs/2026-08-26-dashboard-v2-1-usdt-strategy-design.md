# Dashboard 2.1 USDT 策略版設計

日期：2026-08-26

## 目標

將中文可讀 Dashboard 2.1 收斂成只回答 USDT 放貸策略的頁面，移除決策價值不足且容易與 fUST 混淆的原生資產理論收益區塊，並修正只有 2 天期限才顯示比較基準的問題。

## 獨立輸出

- 原版 `dashboard.html` 保留。
- 中文可讀版 `dashboard_readable_zh.html` 保留。
- 2.1 版新增為 `dashboard_readable_zh_v2_1.html`，不得覆蓋前兩版。
- 三版共用同一份 canonical payload；本次不修改模型、成交代理公式或收集資料。

## 2.1 版面

1. 移除「原生資產利率模型」、條件式理論收益、BTC／ETH／USD 資產選擇與相關說明。
2. 頁面標題與摘要明確寫成「USDT 放貸候選策略」。
3. 使用者只選擇本金 1,000～10,000 USDT，以及借出期限 2／5／10／30 天。
4. 主要結果顯示目前樣本最高策略、白話策略名稱、候選日利率、公開成交代理率、平均等待、閒置比例、30 天代理期望收益及非常低可信度標示。
5. 表格顯示所選期限的收益前三名，以及該期限的兩個固定比較基準。

## 各期限比較基準

對目前選擇的期限 `P`，固定加入：

- 低利率快速成交基準：`q10-pP-w1`。
- 中位利率基準：`q50-pP-w24`。

因此 2、5、10、30 天都會各自顯示同期限基準；基準若已在前三名中只顯示一次。基準是否列出不受與第一名差距大小影響。

## 安全與限制

- 維持唯讀，不呼叫即時 API、不下單、不讀私人帳戶資料。
- 保留完整中文使用限制與台灣時間。
- 公開 candle 碰到利率只視為成交代理，不宣稱個人掛單實際成交。
- fUST 未達正式資料門檻時，整頁維持「非常低可信度實驗值」。
- 不更新 `progress.md` 或 `todo.md`，除非使用者另行要求。

## 驗收標準

- 三個 Dashboard 檔案同時存在，前兩版內容不因產生 2.1 而改變。
- 2.1 不含原生資產模型、資產選擇或條件式理論收益區塊。
- 切換 2／5／10／30 天時，各自顯示相同期限的 q10 快速成交與 q50 中位利率基準。
- 本金只線性換算收益，不改變策略排序。
- 聚焦測試、完整測試及敏感資料掃描均通過。

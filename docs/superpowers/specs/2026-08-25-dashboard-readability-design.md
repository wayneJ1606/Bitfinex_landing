# Dashboard 中文可讀版設計

日期：2026-08-25

## 目標

在不改變模型、資料、公式與原始 Dashboard 的前提下，另外產生一份繁體中文、資訊層級更清楚的唯讀 Dashboard，降低「已建模」與「成交代理可信度」被混為一談的風險。

## 輸出與相容性

- 保留既有 `data/modeling/p0_experimental/latest/dashboard.html`，不得覆蓋或改名。
- 新版固定輸出至 `data/modeling/p0_experimental/latest/dashboard_readable_zh.html`。
- 新舊兩版使用同一份 canonical payload；模型結果與收益計算不得因版面改造而改變。
- 新版仍是單一、自包含、可離線開啟的唯讀 HTML，不連線下單。

## 介面調整

1. 將頁面可見英文標題與七項使用限制改成繁體中文白話說明；必要市場代碼如 `fUST`、`fBTC` 保留。
2. 將「原生資產利率模型」與「fUST 公開市場成交代理」拆成不同狀態區塊：前者顯示是否達最低建模門檻，後者單獨標示非常低可信度。
3. 候選策略以「利率層級｜借出天數｜最長等待」呈現，例如 `q90-p30-w24` 顯示為「高利率｜借出 30 天｜最多等待 24 小時」，原始代碼以次要文字保留。
4. 策略表預設顯示收益最高三項及基準策略，標示「目前樣本最高」與「比較基準」；名目收益差距很小時顯示「與第一名差異極小」。
5. 補上日利率、代理成交率、等待時間與資金閒置的白話說明，並依「資料狀態 → 條件 → 理論收益 → 成交代理 → 策略比較 → 使用限制」排列。
6. 產生時間以台灣時區顯示；原始 UTC 時間仍保留在資料內容中供查核。

## 使用限制中文內容

- fUSD 的市場行為不能替代 fUST。
- 顯示利率是歷史驗證區間的最近一期預測，不是即時未來預測。
- 原生資產理論收益假設立即全額成交；fUST 區塊才包含公開成交代理與等待損失。
- 公開市場價格碰到掛單利率，不代表個人掛單一定成交，因為無法得知排隊順位與可成交容量。
- 成交代理假設資金維持借出至選定期限；實際借款人可能提前還款，使收益降低。
- 收益已扣除公開放貸提供者 15% 手續費。
- USD／USDT 採明示的 1:1 近似顯示；BTC、ETH 仍以原生資產計算後再換算。

## 不在本次範圍

- 不修改模型、可信度演算法、成交代理公式或資料成熟度門檻。
- 不修改任何收集器、排程或私人資料處理。
- 不新增圖表、即時 API、下單功能或自動更新排程。
- 不更新 `progress.md` 或 `todo.md`，除非使用者另行要求。

## 驗收標準

- 執行既有實驗管線後，新舊兩個 HTML 同時存在，且舊檔內容不因產生新版而改變。
- 新版頁面沒有上述七項英文限制，所有狀態與策略名稱可用繁體中文理解。
- fBTC／fETH／fUSD 的建模狀態不再被「fUST 非常低可信度」標籤籠統涵蓋。
- 本金、資產與借出天數篩選仍能正常更新結果；同一情境的新舊版數值一致。
- focused tests 驗證獨立輸出、中文文案、策略翻譯、狀態分離與唯讀安全界線。

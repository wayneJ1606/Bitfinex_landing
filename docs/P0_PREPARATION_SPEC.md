# P0 回測前置準備規格

本文件先固定回測規則，等私人資料滿 7 天後執行，不在資料不足時宣稱最佳策略。

## 1. 資料對齊規則

- 所有時間統一轉為 UTC ISO 8601。
- 公開市場資料以收集時間作為市場狀態快照。
- 私人資料以 `collected_at`、Bitfinex 原始事件時間與事件 ID 保存。
- 成交判定只使用 `funding_trades`；放貸期間與收益狀態使用 `funding_loans` 與 `funding_credits`。
- 同一事件不可跨訓練與測試區間重複使用。

## 2. 必做基準策略

### B1：固定利率

整個測試期間使用固定掛單利率；利率由訓練區間的市場利率分位數產生，不使用測試區間資訊。

### B2：固定利率加固定天數

固定掛單利率與固定放貸天數，作為最簡單的完整策略基準。

### B3：原有利率預測模型

使用現有模型預測下一時間點利率，再以明確規則轉成候選掛單利率；此結果與 B1、B2 比較。

### B4：歷史統計最佳化

依訓練區間估計各利率／天數組合的成交機率與等待時間，再選擇期望收益最高的組合；不得使用測試區間資料調參。

## 3. 統一評估指標

- 成交率：成交事件數 ÷ 掛單事件數
- 平均成交等待時間：從掛單到成交的時間差
- 資金使用率：有收益放貸時間 ÷ 可用總時間
- 利息收益：實際或模擬利息總額
- 閒置成本：未成交資金的等待時間成本
- 淨收益：利息收益 − 閒置成本 − 已知費用
- 本金加利息：本金 + 淨收益
- 年化收益率：依測試期間換算，不以短期結果直接代表長期保證

## 4. 本金情境

- 情境 A：160 USDT 等值
- 情境 B：10,000 USDT 等值
- 先以原始資產計算，再依報告當時的 BTC/USDT 或 ETH/USDT 顯示等值概念。

## 5. 驗證方式

使用時間切分或 walk-forward：前段資料估計成交統計，後段資料只用於測試。報告必須同時列出 B1、B2、B3、B4；若 B4 沒有穩定勝過簡單基準，結論明確記錄沒有證明改善。

## 6. 預計輸出

每個策略輸出：利率、天數、成交率、等待時間、資金使用率、利息、閒置成本、淨收益、本金加利息與驗證區間。另提供策略排名與跨期間穩定性比較。

# 結案報告文字素材筆記

這份文件只保存日後可寫入結案報告的文字重點，不是正式報告，也不處理排版、圖表編號與最終結論。正式章節仍以 [`FINAL_REPORT_OUTLINE.md`](FINAL_REPORT_OUTLINE.md) 為準。

## 專案背景與問題

Bitfinex 放貸並不是利率越高就一定賺得越多。掛單利率較低時可能較快成交，但單位時間收益較少；利率較高時收益看似較好，但可能長時間無法成交，導致資金閒置。本專案希望將這個取捨轉換為可被數據驗證的問題。

最初的建模任務是預測「下一個時間點的市場加權平均利率」。後來依業師建議新增最佳化策略層，使用歷史資料估計不同掛單利率的成交可能性、等待時間、資金閒置與扣費後收益，再與簡單固定策略比較。

## 專案目標與流程

系統流程為：定時收集 Bitfinex 資料，儲存原始紀錄，清洗並整理成每小時特徵，訓練下一時點利率預測模型，再將利率、成交代理、等待與手續費組合成策略比較結果，最後透過 Dashboard 呈現給使用者人工判斷。

最佳化策略是結案報告的應用主線，重點是 USDT 放貸策略比較。長期資料收集則保留本機公開與私人唯讀事件，未來用來校正公開市場代理結果。系統只提供決策輔助，不自動下單，不構成投資建議。

## 資料來源與儲存

公開資料來自 Bitfinex API，包含 funding book、ticker、stats、candles 與 BTC/ETH 價格等資料。GitHub Actions 的公開原始資料保留在 `data/raw/`；本機公開收集器寫入 `data/local_public/`，避免兩個來源共同修改同一份 CSV。兩來源只在模型載入階段以「本機同小時優先、GitHub 補缺」規則合併，原始檔維持分離。私人帳戶的唯讀事件放在 `data/account/`，永不同步到 GitHub。模型與回測輸出位於 `data/modeling/`，資料來源、時間與收集狀態放在 `data/metadata/`。

公開收集器與私人收集器都由 Windows 工作排程器定時呼叫，平時不需要持續開著 PowerShell 視窗。公開資料可供業師從 GitHub 查核，私人資料只保留在本機作為後續校正依據。

## 資料清洗與特徵

原始 funding book 資料會依市場與時間整理，再聚合成每小時的建模資料。特徵包含平均利率、加權平均利率、最高與最低利率、總金額、平均期限、供給與需求筆數、利率價差、前一時點利率、小時與星期等。預測目標是下一時間點的加權平均利率。

「有效特徵」不是指原始 CSV 有多少行，而是某個小時同時擁有建模需要的欄位，並能與下一時點預測目標對齊。缺少關鍵欄位、無法對齊或不連續的原始紀錄，不會被當成可訓練樣本。

2026-11-08 的正式重建中，`fBTC`、`fETH` 與 `fUSD` 各有 2,256 筆有效資料，`fUST` 有 1,820 筆，四個市場均已超過 168 筆基礎建模門檻。資料載入採本機同小時優先、GitHub 補缺，共選取 7,822 個本機快照與 774 個遠端補缺小時。

## 基礎利率預測模型

專案使用兩個簡單 Baseline 與三種機器學習模型作比較。「平均值 Baseline」用過去訓練資料的平均利率當預測；「前一值 Baseline」假設下一小時與現在差不多。線性迴歸尋找各特徵與未來利率之間的直線關係；決策樹以一連串條件分支學習非線性關係；XGBoost 則將多棵較小的決策樹組合起來。

### XGBoost 的白話說明

可以把 XGBoost 想成一組會「輪流改考卷」的小老師。第一棵樹先做一次粗略預測，第二棵樹專門學第一棵樹預測錯誤的地方，後面每棵樹再繼續修正前面留下的錯誤，最後把所有小樹的意見加總成一個預測。

在本專案中，XGBoost 讀取每小時的利率、金額、期限、供需與時間等特徵，嘗試預測下一小時的加權平均利率。它擅長處理「特徵之間互相影響」的情況，例如同樣的資金量在不同時間、不同供需差距下，對利率可能有不同影響。

XGBoost 的缺點是資料太少或參數調得太複雜時，可能只是記住過去樣本，換一段時間就失效。因此它不能因為名字較進階就被當成最好模型，必須依時間順序驗證，再用 MAE、RMSE 與 R2 和簡單 Baseline 公平比較。

需要特別區分：XGBoost 預測的是「下一時點利率」，不是「掛單一定會成交」，也不是直接找到最高收益策略。成交代理、等待與資金閒置由最佳化策略層另行評估。

## 正式結果與仍須保留的限制

2026-11-08 的 USDT 公開歷史已達 75.96 天，共 1,822 筆每小時特徵，完整率 99.95%，最長缺口 3 小時，已通過 60 天、90% 完整率與最大缺口 6 小時的門檻。正式 walk-forward 可輸出 1,400 筆策略結果。以 1,000 USDT、2 天、等待上限 1 小時為例，最佳化含預測、最佳化未含預測與 FRR 的估計淨利息同為 4.652 USDT，因此目前沒有證據顯示利率預測能增加策略淨收益。

公開市場成交代理仍不等於本人掛單的真實佇列順位或成交率。報告可以說明資料門檻、計算流程與正式回測已完成，但不能把估計結果寫成保證收益或投資建議；所有實際掛單仍須人工確認。

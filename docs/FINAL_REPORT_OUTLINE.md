## 一、文件用途

本文件承接最初的《專案企劃書：Bitfinex 放貸決策輔助系統（現實可用版）》，作為正式結案報告的唯一章節依據。報告保留原始的利率預測主題，並將後來確認的 P0 業師建議版納入「成交可能性與放貸策略比較」，不以後來功能取代原始專案目標。

## 二、撰寫與驗收原則

- 只引用可由程式、CSV、JSON、Markdown 或 Dashboard 重現的數字。
- 未達 60 天公開 USDT 資料門檻時，結果一律標示為「實驗結果／資料不足」。
- 公開市場成交代理不等於本人掛單真實成交，不得撰寫為已驗證的成交機率。
- `fUSD` 不取代 `fUST` 的市場行為；USD/USDT 1:1 只能用於金額顯示估算並須明示。
- 私人帳戶資料只用於本機校正與驗證，報告不放入 API 憑證、帳戶識別碼或逐筆原始內容。
- 本系統維持唯讀、人工確認、不自動下單，不宣稱為投資建議。
